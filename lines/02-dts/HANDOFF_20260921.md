### 1.2 MStar-sparse `super` framing (VERIFIED, custom work)
- Each `filepartload` slice for `super`/`cache`/`userdata` starts with 2-byte prefix `F2 07`
  followed by a STANDARD 28 B sparse header (magic `3A FF 26 ED`, v1.0, blk 4096,
  nblks=1310720, per-slice chunk count ~65543-65723).
- Standard sparse parsers fail ("Invalid magic") because of the 2 B prefix AND because each
  slice payload is **LZ4 raw-block compressed**. Proved from the embedded flash script at
  decrypted+0x1000 (13556 B, 351 lines): every sparse slice is preceded by
  `lz4 -d <src> <csize> <dst=0x30200000> <desize(~96-100 MB)>` then `sparse_write`.
- Correct pipeline per slice: `slice bytes → lz4.block.decompress(csize → desize from script)
  → standard sparse (NO F2 07 inside) → expand chunks (RAW/FILL/DC) at absolute image offsets`.
- 32 super slices (offsets `0xD941000 … 0x7E6C1000`, script table), disjoint consecutive block
  ranges (AOSP sparsechunk-style: slice N paints blocks after slice N-1, each slice starts at
  block 0 with leading DON'T-CARE). Final cursor of every slice = 5368709120 (5 GB =
  `mmc create super 0x140000000`). Built to `F:\tclsparse\super.raw` (single file; drive was
  reformatted FAT32→exFAT by the USER after confirming no firmware use depended on FAT32).

## 2. Utopia ABI (VERIFIED, both layers + TD98 back-check)
```
MI_AUDIO_SetDecodeSystem(a,b)            [mik.ko caller / audio.primary caller]
  packs payload {ret=0, a, b}            [userspace sp+0: {0,a@+1,b@+5};
                                          kernel sp+8: {0,a@+9,b@+0xD}]
  UtopiaIoctl(hInst_AUDIO, cmd, payload) [userspace: UtopiaOpen(0x34); kernel: 0x80000034]
  → [instance+0x40] → [ops+0x60] → blr
  → AUDIOIoctl → u16 jump-table on cmd
      0x3C → table[0x1F0] = _MApi_AUDIO_SetDecodeSystem(r4=payload[1], r5=payload[5])
      0x3F → table[0x208] = _MApi_AUDIO_OpenDecodeSystem(struct=payload[4])
      0xCF → table[0x708] = GetAudioInfo2(a=payload[1], b=payload[5], c=payload[9])
```

Semantics: **r4 = OpenDecodeSystem return (AU slot {0,1,2,3,6} or −1), verbatim, no mapping
in handler** (proven at TCL AUDIOIoctl 0x412724/0x412768; TD98 MASTER independently traced
0x3C→_MApi@0x3E52A8→MDrv@0x424E78). **r5 = SetDecodeSystem struct pointer**, same object
MI→MDrv (no copy in kernel path). **+0x10=0xFF passes the gate** (proven on TCL libutopia,
TCL utpa2k.ko, AND TD98 utpa2k_stock.ko@0x3E53B8: `cmp #0xFF; cmpne #0; bne FAIL`).

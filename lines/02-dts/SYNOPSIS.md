# Лінія 02 — DTS-пастрування ⏳ (головна, незавершена)

**Статус: відкрита.** DTS-декодер працює, бітстрім доходитає цілим, але SPDIF-вихід = 0 байт. Блок локалізований у DEC-DSP: дві runtime-умови, слова даних неспостережувані. ARM-бік закритий експериментами повністю.

## Хронологія арки (стисло)
1. **08-29/30** — статика: hashkey/IPCheck ліцензійний гейт у mik.ko; EDID-гейт; Solution A.
2. **09-02/05** — Exp-A/B (utpa2k NOP-и IPID), libmi3 v3; R5 EDID-патч; runtime: декодер стартує, тиша лишається → ліцензія necessary-not-sufficient.
3. **09-06/07** — перебір гіпотез: cmd04 (0x97→0x04) негатив; is-AC3 негатив; діагностичні ядра — ARM-ліцензія закрита; **tier0: `dts_licensee=0` живцем у DEC-DSP**; DM-диференціали: burst-буфер заморожений при DTS.
4. **09-08** — R26-B: «невірно сформований/типізований DTS-burst»; хронологічний леджер консолідує епоху.
5. **09-08/11** — AEON-тулчейн (Reko валідований; ghidra-aeon запакований); фази 27–52: SND-бік симетричний, DTS-ексклюзивні MMIO 0x86C/870/868, статус-блок 0x0C00–07 = перший доведений рантайм-диференціал (AC3 не-нуль / DTS 0 у 20/20). R43: MIU-зонд → **kernel panic → прямі MIU-читання заборонені назавжди**.
6. **09-11/15** — GLM53: SND-боку патч-точки немає; P-A (DEC 0x45FF5) — перші DTS-burst'и на дроті, але 81→4 fallback, licensee=0; K-1 (100 Б у кодек-блобі) — **DEC-патч-лінія вичерпана**.
7. **09-16** — P-BYP марафон: декод відновлено (P-BYP3); монітор-ланцюг ApplySetting (стан 1→5) для DTS не бігає; **чистий efuse-хешей містить DTS-біти** — старі kernel-патчі ламали деривацію.
8. **09-17/24** — Union Alpha + corpus forensics: B=0x22500000 верифіковано; **LOADER TRUTH: /vendor audio_bin патчі ІНЕРТНІ** (DspLoadCode копіює вбудовані блоби); ARM→SE-IDMA 0x112A82–85 виведений; F8/FC тупикові.
9. **09-27/29** — ipauth фальсифіковано остаточно (бітмап FF заливається за 6.4с до аудіо; SE перераховує форс; 0 записів у 7 образах); +0x4F8 = TX-кодек-слово, не ліцензія.
10. **09-30** — MUSE DEC: канал-бітмапа без DTS **by construction**; «форж 5» — null; чистий харнес: ES 2.88 МБ → TX 0 Б; **гейт 0x4604F = `[0x14]-[0x0C] > 0x0D → divert`; блок = 2 runtime-умови (`≤0x0D`, `[0x38]==0x400`); слова неспостережувані (свип 46 386 комірок)**.
11. **10-04** — address==offset доведено (10 544/10 544); гейт 0x4618E декодований: SITE 1/2 = `[+0x28]==1` / `[+0x2C]==1`; єдиний виклик 0x41289.

## Наступний крок (коли продовжите)
Вузьке питання 10-04: **хто пише +0x28/+0x2C відносно базового регістра …+0x14CCC** (контекст виклику 0x41200–0x41295, фільтр зі «382 райтерів» по базовому регістру). Альтернатива з 09-30: DEC-патч публікації [0x14],[0x0C],[0x38] у хост-читабельний регіон 0x11C8. Плюс неотестоване: DTS-HD/LBR файл на пристрої ніколи не програвався.
